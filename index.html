Project 2 requires building an interactive FAQ Accordion Widget from scratch using clean HTML, modern CSS, and vanilla JavaScript.

The core objectives are to create an intuitive collapsible interface, deliver silky smooth CSS transitions, ensure 100% mobile responsiveness, and follow professional front-end engineering best practices.

The animations leverage modern CSS Grid height transitions (grid-template-rows: 0fr to 1fr) combined with opacity and transform animations.

This guarantees a completely fluid animation without jerky layout jumps, fixed height limits, or JavaScript calculation lags. The chevron icons also rotate smoothly with cubic-bezier timing.

Yes, fully compliant with W3C WAI-ARIA Accordion Design Patterns:

  • Semantic Triggers: Built with native <button> elements inside proper heading levels (<h2>).
  • ARIA Attributes: Accurate aria-expanded, aria-controls, and role="region" bindings.
  • Keyboard Navigation: Navigate items using Arrow Down / Arrow Up, jump with Home / End, and toggle using Enter or Space.
  • Focus Rings: Clear, high-contrast :focus-visible indicators for keyboard navigators.

The widget uses fluid typography (clamp() functions), flexible CSS box sizing, and responsive media queries.

On smaller smartphones, touch targets remain generous (minimum 48px height), font sizing scales comfortably, and horizontal scrolling is strictly avoided.

Yes! By default, the widget operates in standard single-open mode (opening one question gently collapses any previously open question).

If you flip the "Multi-open" toggle in the top-right header, you can expand as many questions simultaneously as you want.

All styling tokens are organized at the top of style.css inside :root variables (e.g. --primary-color, --bg-page, --radius-card).

To add new questions, simply copy an <article class="accordion-item"> block in index.html, update the IDs and labels, and it will automatically inherit full animation, search, and keyboard support!
